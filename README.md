# Simple Interest Calculator

## Description
This project is a simple interest calculator that computes the simple interest based on the principal amount, rate of interest, and time period.

The formula used is:

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal (P): The initial amount of money
- Rate (R): Annual interest rate (in percentage)
- Time (T): Time period (in years)

## Output
- Simple Interest calculated based on the given inputs

## Example
If:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:
- Simple Interest = (1000 × 5 × 2) / 100 = 100

## Usage
This calculator can be implemented in any programming language or used for educational purposes to understand how simple interest works.
